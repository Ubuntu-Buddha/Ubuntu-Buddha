## StrangerDanger

**Readers don't act. Actors don't read.**

Untrusted text is read only by subagents that can't run anything. Hooks keep the agents that can run commands from opening the web and the folders you mark untrusted. Those agents get a reader's report, and that report stays data.

[claude-code-stranger-danger](https://github.com/Ubuntu-Buddha/claude-code-stranger-danger) · v0.2.0, experimental · MIT

```
/plugin marketplace add Ubuntu-Buddha/claude-code-stranger-danger#v0.2.0
/plugin install stranger-danger@claude-code-stranger-danger
```

Then `/stranger-danger:setup`, restart Claude Code, and run `/stranger-danger:doctor`.
